# TG-форвардер вакансий

Бот, который читает **публичный** Telegram-канал с вакансиями (без админ-доступа),
отбирает сообщения по ключевым словам и пересылает тебе в личку.

> **Коротко:** обычный Bot API без админки канал читать не умеет.
> Поэтому бот работает как **отдельный аккаунт-пользователь** через Telethon
> (официальный клиентский API Telegram). Аккаунт просто подписан на канал —
> этого достаточно, чтобы видеть новые посты.

---

## Как это работает

```
Публичный канал с вакансиями
        │  (подписка отдельного аккаунта)
        ▼
  Telethon-клиент (main.py)
        │  фильтр по KEYWORDS
        ▼
  Твоя личка (TARGET_CHAT)
```

- Слушает новые сообщения в реальном времени.
- Если текст содержит любое слово из списка — пересылает.
- Если канал запретил forward — копирует текст + фото/видео как новое сообщение.
- Устойчив к лимитам Telegram (FloodWait) — подождёт и повторит.

## Что нужно

1. **Отдельный Telegram-аккаунт** (не основной!). Заведи второй номер / виртуальный номер.
2. **API_ID и API_HASH** — бесплатно на [my.telegram.org](https://my.telegram.org) (подробно ниже).
3. **@username канала**-источника (публичный, вида `@channel_username`).
4. **Твой @username** основного аккаунта (куда слать) или его числовой ID.

### Как получить API_ID и API_HASH на my.telegram.org

1. Открой [my.telegram.org](https://my.telegram.org).
2. Введи **номер отдельного аккаунта** (того, что будет ботом) в международном
   формате, например `+353XXXXXXXXX`, и нажми **Next**.
3. Telegram пришлёт код подтверждения **в приложение Telegram**
   (не SMS!). Введи его на сайте и нажми **Sign In**.
4. В личном кабинете нажми ссылку **API development tools**.
5. Заполни форму **Create new application**:
   - **App title** — любое название, например `MyForwarder`;
   - **Short name** — короткое имя, 5–8 символов, только латиница/цифры,
     например `myfwd123` (если занято — придумай другое);
   - **Platform** — выбери `Other`;
   - **Description** — например `Personal forwarding tool`
     (не пиши слова spam / flood / mass DM — могут отклонить).
6. Нажми **Create application**. Появятся два значения:
   - `api_id` — число (например `12345678`);
   - `api_hash` — строка из 32 символов (буквы + цифры).
7. Скопируй оба и вставь в `.env` (см. пример ниже).
   Если приложение уже создано — форма не покажется, просто скопируй
   уже выданные значения.

> Один номер = один api_id. Не показывай `api_hash` никому и не коммить его в git.
> Если my.telegram.org не принимает виртуальный номер — получи API через
> основной аккаунт, а используй эти же ключи для отдельного (технически работает).

> ⚠️ **Безопасность:** файл `data/*.session` = полный доступ к отдельному аккаунту.
> Не коммить его в git, не показывай никому, включи 2FA в настройках аккаунта.
> Основной аккаунт для этого **не используй** — риск бана и угона.

## Быстрый старт (локально)

```bash
# 1. Скопируй шаблон и заполни своими значениями
cp .env.example .env
# открой .env в редакторе и впиши API_ID, API_HASH, PHONE, SOURCE_CHANNEL, TARGET_CHAT

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Запусти (первый раз попросит код из Telegram — введи его в терминал)
python main.py
```

После первого запуска сессия сохранится в `data/bot.session` —
вводить код больше не нужно.

### Пример `.env`

```env
API_ID=123456
API_HASH=abcdef1234567890abcdef1234567890
PHONE=+353XXXXXXXXX
SOURCE_CHANNEL=@channel_username
TARGET_CHAT=@your_main_username
KEYWORDS=вакансия,работа,требуется,ищем,зарплата,соискатель
```

- `TARGET_CHAT=me` — для теста: в Избранное отдельного аккаунта.
- `TARGET_CHAT=@your_main_username` — тебе в личку с основного аккаунта (рекомендую).
- `KEYWORDS=` (пусто) — пересылать всё подряд без фильтра.

### Как узнать свой числовой ID

Напиши боту [@userinfobot](https://t.me/userinfobot) — он покажет `Id`.
Можно указать ID вместо @username.

## Запуск на сервере (Docker)

Сессию генерируй **локально** (шаг выше), затем перенеси на сервер:

```bash
# на сервере
git clone <твой-репозиторий> tg && cd tg
cp .env.example .env   # заполнить значения
mkdir -p data
cp /путь/до/bot.session data/bot.session   # скопировать сессию с локальной машины

docker compose up -d --build
docker compose logs -f forwarder
```

Бот перезапускается сам (`restart: unless-stopped`), сессия сохраняется в `./data`.

## Настройка фильтра

Ключевые слова — через запятую, регистр не важен. Сообщение пересылается,
если содержит **любое** из них.

```
KEYWORDS=вакансия,работа,требуется,ищем,зарплата,удалённо,офис
```

Советы:
- Добавь хештеги без `#`: `вакансия` найдёт и `#вакансия`.
- Не делай список слишком общим (`работа` даст много шума) — начни с узких слов.
- Хочешь «И» вместо «ИЛИ» (два слова сразу) — скажи, добавлю режим.

## Ограничения и риски (честно)

| Что | Пояснение |
|---|---|
| **Не Bot API** | Обычный бот без админки канал не видит. Здесь работает аккаунт, а не бот. |
| **Риск бана** | Автоматизация аккаунтов — серая зона правил Telegram. Используй отдельный аккаунт, не спамь, не пиши первым незнакомцам. |
| **Лимиты** | Telegram ограничивает скорость отправки. Бот сам ждёт при FloodWait, но при частых срабатываниях может отставать. |
| **Запрет копирования** | Если админ канала запретил пересылку/копирование, бот всё равно прочитает текст и отправит как новое сообщение. Уважай правила канала и не публикуй чужие объявления как свои. |
| **Публичный канал** | Работает для публичных каналов. Для приватных нужен аккаунт-подписчик (тоже работает, но проверь доступ). |
| **История** | Бот видит только **новые** сообщения после запуска. Старые посты не подтянет (можно добавить догрузку истории по запросу). |

## Альтернатива без аккаунта

Для публичного канала можно парсить `https://t.me/s/<username>` без API-ключей,
но это хрупко (ломается при изменениях вёрстки, нет нормального realtime и медиа).
Telethon надёжнее — поэтому выбран он.

## FAQ

**Бот не находит канал?**
Проверь `@username` в `SOURCE_CHANNEL` и что отдельный аккаунт подписан на канал.

**Бот не может написать мне в личку?**
Убедись, что `TARGET_CHAT` — правильный @username/ID и что ты когда-то писал
отдельному аккаунту (Telegram не даёт писать первым незнакомцам).

**Код из Telegram не приходит?**
Проверь номер в `PHONE` (с плюсом и кодом страны) и что аккаунт существует.
Код придёт в само приложение Telegram отдельного аккаунта.

**Хочу слать в свой канал/группу, а не в личку?**
Укажи в `TARGET_CHAT` @username или ID своего канала/группы, где отдельный
аккаунт состоит и может писать.
